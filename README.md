# Text-Based Adventure Game

A console-based mini adventure game developed in Java using object-oriented programming principles.

---

## 🚀 Features

- Text-based gameplay system
- Inventory management
- NPC interaction system
- Dialogue and command mechanics
- Room navigation
- Combat and player status system
- Object-oriented architecture

---

## 🛠️ Technologies Used

- Java
- OOP Principles
- Console-based interaction

---

## 📚 Project Purpose

This project was developed as part of an Object-Oriented Programming course to improve software design, command parsing, and game logic development skills.

---

## ▶️ How to Run

1. Compile the project:

```bash
javac Main.java
```

2. Run the game:

```bash
java Main
```
